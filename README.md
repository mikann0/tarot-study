# タロット学習帳 / Tarot Study Book

タロットを段階的に学ぶためのWebアプリ（日本語・English・Français）。

- 学ぶ：レベル別フラッシュカード、位置の練習問題、進み具合
- 占う：1枚引き〜ケルト十字、段階的なヒント、AI用の文章コピー、記録
- 調べる：カード辞典、スプレッドの解説、リーディング例
- 記録：振り返り、書き出し・読み込み（バックアップ）

記録はブラウザ内（localStorage）に保存されます。

## カード画像について
ライダー・ウェイト版（1909年、パメラ・コールマン・スミス画）の原画を使用しています。米国およびEUではパブリックドメインとされています。
画像は npm パッケージ @cometpisces/tarot-kit-images から取得し、縮小・WebP変換しています。
